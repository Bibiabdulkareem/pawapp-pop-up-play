# Pop Up Play by PawApp 🐾

هدية تفاعلية مجانية من شركة باو أب (PawApp) لعملائها، وتجربة حملة Pet ID.

## Playable web demo
- **Paw Chase:** كرة/هدف متحرك قابل للمس، مع تحكم بالسرعة
- **Paw Art:** الرسم بلمسات الحيوان وحفظ اللوحة
- **Paw Pop:** فقاعات متحركة وصوت فرقعة اختياري
- **Gentle sound effects:** sounds off by default; user must activate sound, adjustable volume
- **PawPlay Challenge:** optional camera/video capture and native sharing (where supported)
- **Pet ID awareness:** download links to PawApp; creating Pet ID happens inside PawApp, not on this demo page
- Tablet-first responsive layout for iPad portrait/landscape, iPhone, Android, Huawei and desktop web browsers

## Publish with GitHub Pages (one-time)
1. Repository **Settings → Pages**
2. Under **Build and deployment**, choose **Deploy from a branch**
3. Choose **main**, folder **/(root)**, then **Save**
4. After GitHub publishes, open: https://bibiabdulkareem.github.io/pawapp-pop-up-play/

The full, self-contained web app is in `index.html`. Pages needs no build or dependencies. New updates to `main` will update the website.

## WhatsApp challenge number
The official PawApp WhatsApp number has **not** been provided yet. In `index.html`, `PAWAPP_WHATSAPP_NUMBER` is intentionally blank, so the direct-to-business WhatsApp button is disabled until the business number is confirmed. Video sharing still requires user action: browsers cannot automatically attach and send videos to a preselected WhatsApp contact.

## Safety
Keep devices stable and supervised. Start with quiet audio; stop if the pet seems uncomfortable. Do not use screen games to distract animals during grooming with sharp tools. This demo does not process medical records or require users to enter pet health data.

**Scope:** Independent repository only. Does not edit PawApp's production systems or other GitHub projects.
